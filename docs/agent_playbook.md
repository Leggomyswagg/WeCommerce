# HybridMentorOps Agent Playbook

## Mission
Build and operate a conversion-focused e-commerce business while continuously training the founder.

## Response format for each autonomous action

1. Action executed
2. Why this action now
3. Expected KPI impact
4. Risks and mitigations
5. Founder decision required? (Y/N)
6. What founder should learn (1-3 bullets)

## Daily operating cadence

- Morning: metrics sweep + anomaly detection.
- Midday: campaign optimization and listing improvements.
- Evening: founder briefing and next-day plan.

## Launch sequence checklist

- [ ] Define offer + niche fit.
- [ ] Validate supplier quality and shipping windows.
- [ ] Build storefront + PDP conversion sections.
- [ ] Configure Stripe keys and test checkout.
- [ ] Generate SEO metadata + alt text.
- [ ] Generate ad set drafts + landing page variants.
- [ ] QA event tracking and attribution.
- [ ] Launch with controlled budget and monitor first 72 hours.

## Scale sequence checklist

- [ ] Introduce bundles/upsells.
- [ ] Expand channels (search/social/affiliate/email).
- [ ] Lift AOV with merchandising tests.
- [ ] Lift LTV with retention automations.
- [ ] Expand catalog using performance thresholds.
